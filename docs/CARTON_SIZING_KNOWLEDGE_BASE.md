# 毅伟纸箱尺寸计算知识库

> 版本：2026-06-04
> 用途：统一成箱尺寸、面纸尺寸、瓦楞纸板尺寸和版面出血的口径，为后续报价公式改造提供依据。
> 结论边界：员工公式和历史订单属于毅伟本地工艺规则；国家标准和客户合同用于成箱尺寸、质量与验收校验，不直接规定统一的面纸放量或出血量。

## 1. 当前结论

1. 系统必须把**成箱尺寸、面纸尺寸、瓦楞纸板尺寸**分开计算和展示，不能用一个公式混算。
2. 员工提供的公式是**面纸基础尺寸公式**，不是瓦楞纸板尺寸公式。
3. 面纸通常比瓦楞纸板大，用于裱贴定位和工艺余量。Yi 已确认 `5-7mm` 为总尺寸差；两张 2026-06 新工艺单进一步验证默认方向为：**面纸长边比瓦楞长边大 `5mm`，面纸短边比瓦楞短边大 `7mm`**。
4. 版面决定附加出血：
   - 上下留白时，可以适当拼紧；
   - 上下有颜色或需要出血时，需要增加尺寸；
   - 两张新工艺单均写“印刷出血宽度要求小于 `10mm`”。这是印刷/版面工艺控制参数，不能直接等同于面纸尺寸公式中的短边余量。
5. 公式结果只能作为**建议尺寸**。设计版面、设备能力和员工复核共同决定最终生产尺寸。
6. 系统优化目标应是：**先保证成箱符合国家标准和客户要求，再在可生产范围内尽量减少面纸、瓦楞纸板和修边浪费**。瓦楞纸板实际下料只能等于或大于建议最低尺寸：偏大仍可生产，但增加用料或修边浪费；偏小会直接造成报废风险。
7. 匿名农化客户订单的客户验收重点是抗压等性能，尺寸通常只做简单验证。系统仍需保留尺寸合规校验，同时应增加抗压/堆码等性能要求和检验依据字段。

## 2. 术语统一

| 名称 | 建议系统字段 | 含义 |
|---|---|---|
| 成箱内尺寸/订单尺寸 | `box_length`, `box_width`, `box_height` | 客户要求的纸箱长、宽、高 |
| 面纸基础尺寸 | `face_base_long`, `face_base_short` | 按成型方式公式得到、未加版面附加量的尺寸 |
| 面纸最终尺寸 | `face_final_long`, `face_final_short` | 基础尺寸加版面、出血、设备余量后的生产尺寸 |
| 瓦楞纸板尺寸 | `board_long`, `board_short` | 裱贴使用的瓦楞纸板尺寸 |
| 成型方式 | `forming_mode` | 单页成型或双页成型；决定单片公式和单箱片数 |
| 面纸拼版方式 | `face_layout_mode` | 单拼或双拼；决定每张面纸承载几片 |
| 瓦楞下料拼版方式 | `board_layout_mode` | 单拼或双拼；可以与面纸拼版不同 |
| 单箱面纸片数 | `face_piece_count` | 单页成型为 1；双页成型为 2，已由两张新订单的投产数量关系支持 |
| 版面类型 | `layout_profile` | 留白、普通、全出血、自定义 |
| 客户胶口要求 | `customer_glue_flap_mm` | 客户/订单指定的胶口控制尺寸，不能作为所有订单统一值 |
| 人工确认尺寸 | `confirmed_*` | 员工或设计最终确认的生产尺寸 |

系统统一使用：`长 × 宽 × 高（L × B × H）`。图片中的“长 × 高 × 宽”为 Yi 书写错误，不代表员工公式口径。

## 3. 员工提供的面纸基础公式

以下公式按手写稿整理，并用 2026-06 新订单进行交叉验证。`+4.5cm` 和 `+2cm` 分别换算为 `+45mm` 和 `+20mm`。其中短边余量不是绝对固定值，会根据成型方式、压痕机和成本取舍调整。

### 3.1 单页成型

```text
面纸长 = 2 ×（纸箱长 + 纸箱宽）+ 4.5cm
面纸短 = 纸箱宽 + 纸箱高 + 2cm
单箱片数 = 1
```

新订单 `YW26-06-01` 精确符合该公式。

### 3.2 双页成型

```text
单片面纸长 = 纸箱长 + 纸箱宽 + 4.5cm
单片面纸短 = 纸箱宽 + 纸箱高 + 短边余量
单箱片数 = 2
```

员工已确认短边余量规则：

```text
单页成型：一般使用 +20mm
双页成型：一般使用 +18mm
满足生产条件时可使用 +15mm，以节省材料成本
```

短边余量与压痕机有关；员工说明相关设备“没有牙叼”。`YW26-06-02` 使用 `+15mm`，属于确认可生产后的降本选择，不是公式计算错误。

面积和成本必须按片数计算：

```text
单箱面纸面积 = 单片面纸长 × 单片面纸短 × 单箱片数
```

### 3.3 双拼

双拼不是成型方式，而是将两片排在同一张面纸或瓦楞下料上的拼版操作。手写稿给出的计算原则是：

```text
双拼拼版尺寸 = 两片单片尺寸沿拼版方向相加 - 约20mm
每张承载片数 = 2
每箱用张数 = 单箱片数 ÷ 每张承载片数
```

例如两片沿短边拼：

```text
双拼长边 = 单片长边
双拼短边 = 2 × 单片短边 - 约20mm
```

历史订单 `460×190×280`、备注“单页成型，双拼”的面纸为 `1345×960mm`：

```text
单片面纸 = [2×(460+190)+45] × [190+280+20] = 1345×490mm
双拼面纸 = 1345 × [2×490-20] = 1345×960mm
```

这验证了手写公式的一种实际用法，但不能证明所有订单都沿短边拼或都固定减 `20mm`。系统必须让员工显式选择拼版方向和减量，并对双拼结果提示工艺复核。瓦楞双拼的减量规则仍缺员工案例，不能假装已经确认。

## 4. 面纸、瓦楞和版面附加量

### 4.1 面纸与瓦楞纸板

结合 Yi 确认、历史数据和两张新工艺单，默认建议规则可写为：

```text
瓦楞建议长边 = 面纸最终长边 - 5mm
瓦楞建议短边 = 面纸最终短边 - 7mm

瓦楞实际下料长边 >= 瓦楞建议长边
瓦楞实际下料短边 >= 瓦楞建议短边
```

其中 `5mm`、`7mm` 都是对应尺寸的**总差值**，不是每边差值。瓦楞实际下料偏大只增加浪费；偏小会产生直接报废风险。系统仍应支持人工覆盖，并记录偏大产生的预计浪费。

### 4.2 版面与出血

出血是印刷图文超出模切/裁切边界的版面工艺参数，通常按单边记录。它与面纸下料尺寸有关，但不是同一个概念，不能直接用出血值解释公式常量或例外调整。

建议把出血和面纸尺寸调整建成两个独立字段：

| 版面情况 | 系统处理建议 |
|---|---|
| 上下留白 | 允许员工判断是否减少面纸尺寸附加量 |
| 普通版面 | 使用默认面纸尺寸公式 |
| 上下有颜色/全出血 | 记录实际单边出血值，并由设计确认面纸尺寸是否需要调整 |
| 特殊结构/不确定 | 标记“必须设计复核”，使用人工最终尺寸 |

推荐记录四边值 `bleed_top/right/bottom/left`，并设置单边上限检查；另设 `face_size_adjust_long/short` 记录面纸尺寸相对默认公式的调整量及原因。

## 5. 历史订单验证

本地数据库中：

| 数据项 | 数量 |
|---|---:|
| 工艺单总数 | 2,155 |
| 有面纸尺寸 | 1,867 |
| 有瓦楞纸板尺寸 | 2,054 |
| 同时有面纸和瓦楞尺寸 | 1,842 |

将长短边按最接近方向匹配后，`1,700 / 1,842 = 92.3%` 的订单呈现以下模式：

- 一个尺寸差为 `3-9mm`；
- 另一个尺寸差为 `5mm`；
- 面纸尺寸大于瓦楞纸板尺寸。

最常见的尺寸差组合：

| 面纸减瓦楞的两个尺寸差 | 订单数 |
|---|---:|
| `+7mm / +5mm` | 916 |
| `+5mm / +5mm` | 465 |
| `+9mm / +5mm` | 173 |
| `+6mm / +5mm` | 69 |
| `+3mm / +5mm` | 53 |

这能证明 `5-7mm` 是很强的毅伟本地经验规律，但不能单独证明具体计算方向或适用条件。

### 5.1 2026-06 新订单验证

| 批次 | 成型方式 | 成箱尺寸 | 面纸尺寸 | 瓦楞尺寸 | 面纸减瓦楞 | 公式验证 |
|---|---|---|---|---|---|---|
| `YW26-06-01` | 单页成型 / 单拼 | `362×288×318` | `1345×626` | `1340×619` | 长边 `+5`、短边 `+7` | `2×(362+288)+45=1345`；`288+318+20=626` |
| `YW26-06-02` | 双页成型 / 单拼 | `370×280×232` | `695×527` | `690×520` | 长边 `+5`、短边 `+7` | `370+280+45=695`；`280+232+15=527` |

两单还提供了以下证据：

- 单页成型订单约为单箱 1 片面纸/瓦楞；双页成型订单约为单箱 2 片。
- 两单均注明“印刷出血宽度要求小于 `10mm`”和“印刷胶口控制 `13mm`”；Yi 已确认胶口 `13mm` 是客户/订单要求，不能作为所有订单的统一值。
- `YW26-06-01` 生产计划单明确列出箱体外径尺寸偏差 `±5mm`；建议系统把尺寸偏差做成订单级字段，不直接视为所有订单的统一值。
- `+45mm` 是手写公式常量，并在两种成型方式的新订单中均成立；客户胶口要求 `13mm` 是独立字段，不能与公式常量混算。
- 短边余量属于可优化工艺参数：单页一般 `+20mm`，双页一般 `+18mm`；确认设备和版面允许时可降到 `+15mm` 节省成本。工艺单中的出血 `<10mm` 是独立要求。

### 5.2 成型方式与双拼不是同一维度

历史备注提供了直接证据：

| 备注模式 | 数量 | 说明 |
|---|---:|---|
| 单页成型且双拼 | 50 | 单页成型可以同时使用双拼 |
| 双页成型且双拼 | 46 | 双页成型也可以同时使用双拼 |
| 面纸双拼、瓦楞纸板不双拼 | 125 | 面纸与瓦楞拼版方式可以不同 |

因此，旧系统把“双拼”放在“成型方式”选择框中属于字段建模错误，不能继续沿用。

## 6. 国内标准与行业资料

### 6.1 国家标准边界

- **GB/T 6543-2025《运输包装用单瓦楞纸箱和双瓦楞纸箱》**：2025-05-30 发布，2025-12-01 实施，当前有效。规定纸箱分类、质量要求、尺寸偏差、搭接舌等，并在资料性附录 C 说明 0201 型纸箱展开尺寸、外尺寸和内尺寸之间的关系。
- **GB/T 6544-2008《瓦楞纸板》**：截至 2026-06-04 仍为现行标准。
- **GB/T 6544-2026《瓦楞纸板》**：2026-04-30 发布，2026-11-01 实施；目前尚未生效。
- **GB/T 7705-2008《平版装潢印刷品》**：用于平版印刷质量要求，不能作为统一纸箱出血尺寸公式。
- **GB/T 4857.4-2008《包装 运输包装件基本试验 第4部分：采用压力试验机进行的抗压和堆码试验方法》**：可作为抗压/堆码试验方法来源之一。
- **GB 12463-2009《危险货物运输包装通用技术条件》**：仅在具体产品被认定为危险货物时适用；不能仅因“化工产品、出口订单”自动套用。

国家标准没有规定“面纸必须统一比瓦楞大 5-7mm”或“全出血必须统一增加 5-10mm”。这些属于工厂设备、裱贴定位和版面设计共同决定的工艺规则。

系统应把国家标准和客户合同作为验收约束，把毅伟工艺公式作为生产尺寸建议规则。客户要求严于国家标准时，应按客户要求执行。

两张 2026-06 匿名农化客户生产计划单仍写“出厂检验应符合 `GB/T 6543-2008`”。由于 `GB/T 6543-2025` 已于 2025-12-01 实施并代替 2008 版，建议更新生产计划单模板；若客户合同明确指定旧版，则需单独保留合同依据。

### 6.2 行业资料结论

- 裱纸机需要定位规矩边，面纸通常设计得比瓦楞底纸略大；余量越大越容易定位，但材料损耗也越高。
- 出血和放量需要结合设备、结构、材料和版面确定，不能只用一个行业通用数值。
- 成箱尺寸、纸板制造尺寸、压线、开槽、接合舌和设备误差需要分别考虑。

## 7. 2026-06-04 系统改造状态

本次改造已完成：

1. 新增独立 `sizing_engine.py`，统一单页/双页、面纸拼版、瓦楞拼版、片数和单箱材料面积计算。
2. 删除旧报价台默认“`双拼×双拼`”以及 `+50/+20`、`+30/+15` 两套冲突公式。
3. 成型方式、面纸拼版和瓦楞拼版拆成三个必须确认的输入；系统不再按历史占比猜测，空备注或无关备注显示为“未识别”。
4. 长边默认 `+45mm`；短边自动按单页 `+20mm`、双页 `+18mm`，并支持经确认后的 `+15mm`。
5. 出血、客户胶口、尺寸偏差、抗压要求和面纸版面调整独立输入，不再混入尺寸常量；尺寸偏差默认未指定，不能把某张订单的 `±5mm` 套用于全部订单。
6. 报价成本改按面纸和瓦楞各自的**单箱总面积**计算；双拼会按每张承载片数换算每箱用张数。
7. 新增两张 2026-06 订单和双拼实际案例的自动回归测试。
8. 瓦楞双拼缺员工实单，报价界面会强制填写员工确认的最终瓦楞下料尺寸，避免用未确认建议值直接报价。

仍未完成：

1. 瓦楞双拼的方向和减量缺员工实际案例；尺寸引擎可生成待复核建议，但报价界面会阻止直接使用，必须填写员工确认的最终瓦楞尺寸。
2. 抗压要求已能记录，但尚未根据抗压目标自动反选纸板材质。
3. 历史数据库仍从备注派生成型/拼版字段，尚未迁移为工艺单原生结构化字段。
4. 尚未完成新尺寸引擎的真实员工 UAT 和最终签字确认。
5. 现有合同价 MAPE 使用预核单已知板材面积，属于**条件价格评估**，不能当作尺寸引擎或端到端报价精度。

## 8. 系统改造建议

下一版尺寸引擎建议按以下顺序计算：

```text
成箱尺寸
  → 按成型方式计算面纸基础尺寸和片数
  → 按版面类型增加或减少附加量
  → 得到面纸建议尺寸区间
  → 按毅伟本地规则计算瓦楞建议尺寸
  → 员工/设计确认最终尺寸
  → 校验成箱尺寸与质量要求
  → 按最终尺寸计算材料面积、成本和预计浪费
```

必须具备：

1. 面纸和瓦楞两套独立公式及独立人工覆盖值。
2. 成型方式与单箱片数显式记录；单页成型 `1` 片、双页成型 `2` 片。
3. 长边默认常量使用 `+45mm`；短边余量按单页 `+20mm`、双页 `+18mm` 推荐，允许员工在确认可生产时调整到 `+15mm`。客户胶口要求、设备条件、订单级尺寸偏差、四边出血和调整原因必须独立记录。
4. 同时展示“基础值、建议区间、最终确认值”。
5. 短边余量低于成型方式默认值时，要求记录设备条件与调整原因；双拼、全出血或特殊结构提示“需要设计复核”。
6. 公式版本、来源和人工修改原因可追溯。
