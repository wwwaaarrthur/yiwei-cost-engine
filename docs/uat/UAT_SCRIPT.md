# UAT Script

> Only for execution by a real business user. Codex, Yi, or any agent must not fill this as if UAT happened.

## Task 1: Quote A Standard EB Domestic Order

Scenario: the user opens the public or internal app, uses the quote workbench, enters a standard EB domestic order, and reviews the suggested quote.

Success standard:

- Quote result renders.
- Cost breakdown is visible.
- User can explain whether the output is usable, needs revision, or is not usable.

## Task 2: Review A BC Export Risk Case

Scenario: the user checks a BC export-like order and reviews whether the system surfaces the high-error / special-configuration risk.

Success standard:

- The user can identify the risk message or missing-data question.
- The user can state what extra information is needed before sending the quote.

## Task 3: Find Similar Historical Orders

Scenario: the user searches for a related historical order or reviews the similar-order section after quoting.

Success standard:

- Similar-order evidence is visible.
- The user can say whether the references are relevant enough for review.

## Completion Rule

UAT is complete only when a real business user performs the tasks and the record template is filled with dated evidence. A prepared script is not UAT evidence.
